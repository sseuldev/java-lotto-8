# java-lotto-precourse

## 요구사항 정리 📑

1. 입력 1 : 로또 구입 금액을 입력한다. 이때, 구입 금액은 1,000원 단위로 입력 받는다.

   ☑️ `구입금액을 입력해 주세요.`

2. 출력 1 : 발행한 로또 수량 및 번호를 출력한다. 이때 로또 번호는 오름차순으로 정렬한다.

   ☑️ `(수량)개를 구매했습니다.`

    - 로또 번호의 숫자 범위는 1~45까지이다.
    - 1개의 로또 발행 시 중복되지 않는 6개의 숫자를 뽑는다.
    - 로또 한 장의 가격은 1,000원이다. 로또 구입 금액에 해당하는 만큼 로또를 발행한다.

3. 입력 2 : 당첨 번호를 입력한다. 번호는 쉼표(,)를 기준으로 구분한다.

   ☑️ `당첨 번호를 입력해 주세요.`

4. 입력 3 : 보너스 번호를 입력한다.

   ☑️ `당첨 번호를 입력해 주세요.`

5. 출력 2 : 당첨 내역을 출력한다.

   ☑️ `당첨 통계`

    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

6. 출력 3 : 수익률을 출력한다. 이때, 수익률은 소수점 둘째 자리에서 반올림한다.

   ☑️ `총 수익률은 (수익률)%입니다.`


- Enum을 적용해본다.
- 기능에 대한 단위 테스트 코드를 작성한다.
- 사용자가 잘못된 값을 입력할 경우,`IllegalArgumentException`를 발생시키고 [Error]로 시작하는 메세지를 출력한 후 그 부분부터 입력을 다시 받는다.
- `camp.nextstep.edu.missionutils`에서 제공하는`Randoms`및`Console`API를 사용하여 구현한다.

  ✅ Random 값 추출 : `pickUniqueNumbersInRange()`

  ✅ 사용자 입력 : `readLine()`

## 구현할 기능 목록 ⚙️

## 문자열 입출력 기능 💡
### ✔️ InputView

1. 로또 구입 금액을 입력받는다.
2. 당첨 번호를 입력받는다.
3. 보너스 번호를 입력받는다.

<br />

### ✔️ OutputView

1. 발행한 로또 수량 및 번호를 출력한다.
2. 당첨 내역을 출력한다.
3. 수익률을 출력한다.

<br />

## 로또 발행 및 당첨 기능 💡
### ✔️ LottoController

- 입력 → 로또 발행 → 로또 당첨 → 상금 및 결과 출력 흐름 제어

<br />

### ✔️ Lotto

1. 로또 하나를 담당하는 도메인 객체이다.
2. 당첨 로또 번호의 유효성에 대한 예외를 처리한다.
3. 6개의 로또 번호를 오름차순으로 정렬한다.

<br />

### ✔️ TotalLotto

- 사용자가 구입한 로또 전체를 관리하는 일급 컬렉션이다.

<br />

### ✔️ LottoAmount

1. 사용자가 구입하고자 하는 금액을 담당하는 도메인 객체이다.
2. 구입 금액의 유효성에 대한 예외를 처리한다.
3. 금액에 따른 로또 개수를 계산한다.

<br />

### ✔️ LottoInputParser

1. 입력한 로또 당첨 번호를 쉼표를 기준으로 분리하는 객체이다.
2. 로또 번호의 타입에 대한 예외를 처리한다.

<br />

### ✔️ LottoMaker

1. 구입 금액에 따른 로또를 생성하는 도메인 객체이다.
2. NumbersGenerator를 활용하여 로또를 랜덤으로 생성한다.

<br />

### ✔️ Bonus

1. 사용자가 입력하는 보너스 번호에 대한 도메인 객체이다.
2. 보너스 번호의 유효성에 대한 예외를 처리한다.

<br />

### ✔️ Winning

1. 사용자가 가진 로또와 실제 당첨 로또를 비교하여 추첨을 진행하는 도메인 객체이다.
2. 일치 결과와 그에 따른 수익률을 계산한다.
3. 보너스 번호와 당첨 번호 간 중복 예외를 처리한다.

<br />

### ✔️ LottoRank

- 일치 개수와 당첨 상금을 나타내는 Enum 클래스

<br />

### ✔️ NumbersGenerator, RandomNumbersGenerator

- 중복 없는 랜덤 숫자를 원하는 개수에 맞게 생성

<br />

## 기타 💡

<br />

### ✔️ ErrorMessage

- 예외 메시지 전용 Enum 클래스

7. 보너스 번호가 당첨 로또 번호와 중복된 경우
8. 보너스 번호가 숫자가 아닌 경우
9. 보너스 번호가 1~45 사이가 아닌 경우
